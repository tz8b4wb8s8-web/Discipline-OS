# DISCIPLINE OS

Personal execution and academic productivity dashboard built with React, TypeScript and Vite.

## Source bundle
Download `discipline-os-source.tar.gz` from the repository and extract it. Then run `npm install` and `npm run dev`.

## Status
Initial frontend scaffold. Tasks and habits use browser localStorage. ManageBac screen is a setup/status UI only; live API integration, authentication, cloud persistence, AI coaching and notifications are not implemented yet. Never store API tokens in frontend code.
