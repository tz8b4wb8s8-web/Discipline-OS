# DISCIPLINE OS

A lightweight, responsive student productivity dashboard published with GitHub Pages.

## Publish
1. In repository Settings → Pages, set the source to **GitHub Actions**.
2. The workflow in `.github/workflows/deploy.yml` deploys the site on every push to `main`.
3. The site URL is `https://tz8b4wb8s8-web.github.io/Discipline-OS/`.

## Features
- Daily task list with subject categories
- Habit checklist
- Focus timer (25, 50, and 90 minutes)
- DP1 subject overview
- Local browser storage for tasks and habits

Data is stored in the browser on the device where the site is used. This is a static front-end app; it has no account system or cloud sync.
